# Candidate Pipeline

## Pipeline stages
1. Sourced -> Screened -> Interview loop -> Offer -> Hired/Declined
2. Every stage transition records date and owner.
3. No candidate advances without written screen notes.

## Status hygiene
- Weekly pipeline review: aging alerts past stage SLA.
- Declined candidates get a reason code.
